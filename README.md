# timelessxi.gg

Website for Timeless XI: Reforged, a level 75 Final Fantasy XI private server launching December 2026. Static HTML served by GitHub Pages.

`data/nms.json` is generated from the server repo (timed NM list, zone data, item tables). The NM Tracker reads live status from `LIVE_URL` in `nm-tracker.html` once the server publishes it.
