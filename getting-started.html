Getting started

Back to Vana'diel in five steps

You'll need a Windows PC with FINAL FANTASY XI installed. Everything else comes with the Timeless Launcher.

  1. 1

    Create your account

    Pick a username and password. This is your Timeless login, separate from any Square Enix account.

    Create account
  2. 2

    Install FINAL FANTASY XI

    Install the PC game and let it fully update. Already have it installed? Skip ahead.

  3. 3

    Download the Timeless Launcher

    The launcher includes Ashita v4 and xiloader, so there's nothing else to set up. Unzip it anywhere you like and open Timeless Launcher.

    Download for Windows
  4. 4

    Install the Timeless game files

    The new Records of Eminence pages, the hourglass linkshell icon and Timeless items need a few updated game files. Close the game first; Windows will ask for permission once.

  5. 5

    Press Play

    Sign in, choose your add-ons and graphics, and play. The launcher makes sure your macros and settings save, and backs them up before each session.

    Once you're in, say hello in the Timeless linkshell, then step outside the city gates and open /cm to call your companions. The new player guide covers everything else.

Your first commands

Type these in the chat box once you're in.

/cm
Companion manager: call and set up your companions
/craft
The craftbook: recipes, gathering, Hearth, garden and Champions
!gather
Gathering levels, and whether you're near the rich spot
!guild
Artisans Guild standing and requests
!bounty
Today's bounties
!chores
Your moogle's two daily chores
!shop
Spend grubstakes

Need a hand?

  • Macros not saving? Use Maintenance › Fix saving in the launcher.
  • Wrong resolution? Set it on the launcher's Graphics tab, not in the game's config tool.
  • Still stuck? Ask in the Discord's help channel.
